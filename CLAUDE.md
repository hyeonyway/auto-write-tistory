# Claude Instructions

Follow `AGENTS.md` and `GROUND_RULES.md`.

Key rules:

- Do not commit directly to `main`.
- Work on a feature branch.
- Rebase on `main`, resolve conflicts, then squash merge.
- Use 4-space indentation.
- Run pre-commit checks before claiming work is ready when possible.
- Never store or log Kakao/Tistory credentials.
